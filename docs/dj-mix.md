# Folia DJ Mix：本 Fork 的重点功能

> 桌面端专有。设置 → 播放控制 → 混音过渡，打开开关，模式选 **Folia DJ Mix**。网页版、遥控页和手机浏览器没有这一项。Windows 直通开着时，整段混音过渡（含 DJ Mix）关掉，关掉直通后按原设置恢复。

上游的 Automix 在歌**快放完**时，按结尾的节拍和结构把下一首接进来。DJ Mix 做的是另一件事：两首歌在**曲中**叠在一起走一段，下一首先淡进来，当前这首再淡出去，听起来是交接，不是把歌切成短片。

它仍用上游那套双轨 Web Audio（两个 `<audio>`、分析出来的节拍和段落、分频段增益）。规划是本 Fork 自己的：`src/services/automix/djMixPlanner.ts`。不改上游 Automix / 交叉淡化的门槛。

---

## 打开之后会听到什么

每一次能做的自动切歌都按下面的关系选一段重叠。重叠最长 25 秒，并且不超过当前这首的 18%、下一首的 22%。**不改变正在听的这首歌的速度**（下一首也不做时间拉伸）。

速度用全曲 BPM，不用结尾那几秒的 BPM。差多少按上游 `tempoMatch` 的档：

| 两首的速度 | 重叠 |
| --- | --- |
| 已经一样（相差不到 1.5%） | 32 / 16 / 8 拍里放得下的最长一段（八小节、四小节、两小节） |
| 接近（不超过约 5.9%） | 16 / 8 拍 |
| 两首都很燥（全曲 BPM 都至少 126），而且没有差到 25% 以上 | 同样按 16 / 8 拍交接，从响的段落走，低音只交给一边 |
| 两首都很燥，但速度差超过 25% | 8 秒，放不下就 6 秒；长洗会让两套鼓一起响 |
| 调性差半音或三全音 | 8 / 6 秒，不给一段长乐句让不协和挂着 |
| 其余对不上的组合 | 12 秒，放不下就 9 秒：下一首先淡入，当前这首再淡出 |

对得上拍、或者两首都燥且不是差很远时，低音在重叠中段换手，同一时间只有一首有低音。对不上时不做低音换手，从重叠一开始就收掉出歌的高音，进歌的高音也先按住，避免两套镲片叠满。

两首都很燥时，出歌不能停在满电平上：重叠中间几乎不停留，高音最多收 16 dB，中频一起收 8 dB，淡出比慢歌更明显。慢歌的高音大约收 9 dB，而且主要在换手之后。

人声还在唱的地方、已经空掉的地方、以及慢歌里仍顶在峰值上的地方，尽量不拿来当交接。乐句开头那一拍算进场，不算把一句歌词切成两半。

没有完整分析时仍重叠约 12 秒：当前这首大约在 78% 处出场（再往后还有 86%、92% 两个备选），下一首大约在 20% 处进场，进场不超过 45 秒。已经在前 62% 结束的响段落不再拿来提前离场。分析时长和文件差在 `max(15 秒, 曲目时长的 8%)` 以内仍用这份分析；差得像另一个版本才放弃这次 DJ 点，改走上游 Automix 的规划。

提前约 6 秒把下一首装上。节拍对不齐时，先把进场播放头挪到拍上；低音换手且还差超过 0.35 拍时缩短重叠，而不是收成一两秒的切断。拍点吸附最多吃掉计划重叠的大约 10%。

装不上、调度不了、或文件短到放不进这个点时，这一次不混，歌继续按队列走。曲首曲尾那各 30 秒的分轨窗口不负责曲中这一点。

## 什么歌能混，什么不能

DJ Mix 要读到音频才能分析。读不到字节的来源不会进入这一档。

| 来源 | 能不能 DJ Mix |
| --- | --- |
| 网易云、QQ、酷狗、YouTube Music、本地文件、Navidrome，以及其它能交给页面 `<audio>` 的地址 | 可以。桌面端会去分析。 |
| Spotify 标准播放（librespot，应用自己的音频地址） | 可以。 |
| Spotify Soloist | 不行。声音在 Soloist 里，Folia 拿不到文件。 |
| Apple Music 伴随播放器 | 不行。声音不离开伴随程序，没有可供分析的地址。 |
| 网页版 / 遥控页 / 手机浏览器 | 设置里没有 DJ Mix。选不了时会退回上游 Automix。 |
| 直通模式开着 | 混音过渡整项禁用，包括 DJ Mix。直通不经过这段 Web Audio。 |

## 和上游 Automix、交叉淡化的差别

同一条开关，三种模式（设置 → 播放控制 → 混音过渡）：

- **交叉淡化**：按你设的秒数，在歌尾相接。
- **Automix**：上游的智能过渡，主要接在歌尾，可以变速、切拍、抛回声。
- **Folia DJ Mix**：曲中按乐句重叠。不拉伸当前这首。对不上速度时保留一段长叠化，不收成短切。

直通、均衡器、ReplayGain 的关系与上游 Automix 相同：直通开着时这些都不作用在 helper 的输出上。见 [Hi-Fi 直通](hifi.md)。

## 代码

| 文件 | 做什么 |
| --- | --- |
| `src/services/automix/djMixPlanner.ts` | 选出场点、进场点和重叠长度 |
| `src/services/automix/djMixTiming.ts` | 人声区间、相位、进场预卷（最长约 8 秒） |
| `src/services/automix/djMixAnalysis.ts` | 曲中段落的响度 |
| `src/services/automix/automixSession.ts` | 把方案写成增益和分频段曲线；燥歌的淡出在这里加强 |
| `src/services/automix/useAutomixDecks.ts` | 两个播放元素；曲中提前扫描，不必等到歌尾 |
| `src/services/automix/transitionStrategy.ts` | `djMix` 模式；`canUseDjMix` 只在桌面端且能分析时为真 |
| `src/components/modal/settings/pages/PlaybackPage.tsx` | 设置项 |

回归：`npx vitest run -c vitest.config.ts test/unit/automix/djMixPlanner.test.ts test/unit/automix/automixSession.test.ts test/unit/automix/signalAnalysis.test.ts`。

听感上的常数（重叠秒数、淡出深度、BPM 门槛）是按试听定的。改它们之前先读 `src/services/automix/README.md` 开头的约定：上游 Automix 的门槛不要顺手改掉。
